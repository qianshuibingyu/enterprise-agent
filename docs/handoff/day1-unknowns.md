## 已确认但不再列为待确认

- 渠道为 WhatsApp、Gmail、Outlook；项目完成目标是真实接口，模拟链路只用于功能测试。真实 Token/API 在实际开发 MVP 验证阶段准备。
- 三个渠道应抽象统一输入和输出，形成统一接入规范；具体映射以实际接口为依据。
- 抓取时间为 UTC+8：08:00、09:30、11:00、14:00、15:30、17:00；不含 12:00、18:00；周日及中国大陆法定节假日不抓取；管理员可修改；每次处理未读信息，静默时段不等于已处理。
- Agent 无依据、无法判断或无法处理时，通知当前节点负责人、管理员和全链路有操作权限的人员。
- 外网搜索仅用于概念、产品和基本信息，不用于产品独特信息、物流或库存。
- 客户已有业务员负责时，Agent 停止跟进和回复建议；业务员在项目外联系客户。群聊仅提醒运营有进度，不进行处理；私聊不安排定期跟进提醒。
- 固定发件人表单邮件进入白名单后，提取/翻译并生成处理项，不生成回复建议且不默认忽略；已成交邮件在运营授权范围无解时提醒运营，由运营联系业务，Agent 不介入或监听。
- 报表的数据分析和简单方向性建议暂不纳入当前开发，保留后续外部系统扩展空间。
- 工程、采购、生产仅保留资料和链路记录；不实现部门内部操作。P2 外部集成、OCR、额外渠道不纳入当前开发，只保留规范/扩展空间。
- 链路失效条件由业务/运营决定，不由 Agent 决定；失效链路可重新标记为跟进中；仅失效链路涉及 30 天清理方向，账号注销不自动清空。
